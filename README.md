# 📊 Validador de Faturas

## 📝 Descrição
Sistema automatizado para validação de faturas empresariais. Lê planilhas Excel, aplica regras de negócio e gera relatórios detalhados de validação.

## ⚙️ Funcionalidades
- ✅ Validação automática de dados de faturas
- 📈 Geração de relatórios em Excel
- 🔍 Detecção de problemas nos dados
- 📊 Estatísticas de validação
- 🎯 Interface simples e intuitiva

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Pandas** - Manipulação de dados
- **XlsxWriter** - Geração de relatórios Excel

## 📋 Pré-requisitos
- Python 3.7 ou superior
- pip (gerenciador de pacotes Python)
